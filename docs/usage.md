# Usage

```bash
zero-threat-check --describe
zero-threat-check update --kev
zero-threat-check scan --kev-inventory
zero-threat-check scan --phone /path/to/backup
zero-threat-check tui
zero-threat-check dashboard   # http://127.0.0.1:8765
```

Reports include grades, gaps, KEV due dates, and the mandatory clean ≠ safe statement.
Logs: ~/.local/share/zero-threat-check/logs/
