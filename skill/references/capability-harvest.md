# Capability Harvest Pattern

Harvest the *what*, not the *how*.

1. Document artifacts, indicator types, grades, and gaps.
2. Implement as a reader under `src/zero_threat_check/readers/`.
3. Register so `--describe` exposes it.
4. Keep scan path network-blocked.
5. Add positive/negative fixtures and gap tests.
6. Cite every source.
7. Update skill references.

Never copy code from copyleft tools. Reimplement the capability.
